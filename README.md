# Web Programming Assignment - Word Guessing Game

## Description
This project is a simple web-based Word Guessing Game created using HTML, CSS, and JavaScript. 
It fulfills the Web Programming assignment requirements by demonstrating basic front-end development concepts.

Selected Topic: **Simple Word Game**

## Features
- **Hint System:** Displays a hint for each word to help the player.
- **Interactive Keyboard:** On-screen A-Z keyboard for easy interaction.
- **Life Counter:** Player starts with 5 lives and loses one for each incorrect guess.
- **Reset Button:** Allows the user to restart the game with a new random word.

## File Structure
- `index.html` - The structural markup of the game.
- `style.css` - Styling and layout design.
- `script.js` - Game logic and DOM manipulation.
- `README.md` - Project description and documentation.

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)
